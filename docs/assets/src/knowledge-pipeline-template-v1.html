知識抽取 Pipeline Template v1

固定六個可觀察的交付階段，保留 stage 內部的 asset 拆分自由； validation 獨立成為發布門禁，publish 只做原子發布。

Template 的核心契約 每個 stage 必須有一個 terminal asset。前端只讀固定 stage 與狀態； 跨 stage 只接 terminal asset；validation 未通過時 publish 不得執行。
固定交付邊界 Validation gate Dagster 狀態投影 原子發布 RUN_SUCCESS ≠ PUBLISHED
1 · 六階段固定 asset 鏈 每個方塊是 stage terminal；灰色小框是下游可依賴的交付物
1Source

可讀性、MIME、hash、doc_id/version、tenant 與來源 URI。這裡不解析內容。

BFF task / stage projection

只認本次 task 的 run；套用固定 stage 優先級；sensor 回推 + 定時對賬；對同一事件做 idempotent upsert。
